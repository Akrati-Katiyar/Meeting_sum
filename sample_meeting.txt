[08:31 - 15:45] Discussion: Production Latency & Infrastructure
Arjun: Moving on to the production latency. Last Tuesday during peak traffic, API response times spiked to 1.8 seconds on the search endpoint.
David: We analyzed the logs and traces. The culprit is unindexed queries hitting the PostgreSQL database alongside Redis cache invalidation spikes.
Arjun: We need composite indexes added on the product catalog tables and an increased TTL on Redis cache entries.
David: I can prepare the database migration script and apply the indexing in the staging environment by tomorrow afternoon.
Priya: Will there be any expected downtime during staging deployment?
David: Zero downtime. The index will be created concurrently. Once validated in staging, we can push to production during our maintenance window on Sunday at 2 AM.
Priya: Approved. David owns the staging migration by Wednesday and production rollout on Sunday.

[15:46 - 21:10] Discussion: Budget & Next Steps

David: I have written an AWS Lambda script to auto-stop all non-production EC2 instances at 8 PM on weekdays and over the weekend. That alone will save approximately $1,400 per month.
